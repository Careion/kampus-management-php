# Kampus Management PHP

Project sederhana untuk praktikum PHP + MySQL.

## Struktur file
- `koneksi.php` : file koneksi database
- `mahasiswa.php` : menampilkan data mahasiswa beserta program studi
- `fakultas.php` : menampilkan data fakultas

## Cara menjalankan
1. Pastikan XAMPP / Laragon aktif.
2. Import file SQL `db_kampus_pertemuan4-.sql` ke phpMyAdmin.
3. Pindahkan folder project ke `htdocs`.
4. Buka browser:
   - `http://localhost/kampus-management-php/mahasiswa.php`
   - `http://localhost/kampus-management-php/fakultas.php`

## Catatan
- Gunakan username `root` dan password kosong untuk lingkungan praktikum lokal.
- Untuk server nyata, gunakan username database khusus dengan hak akses terbatas.
